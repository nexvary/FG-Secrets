# FG Secrets | أسرار الصناعات

موسوعة صناعية عربية من FG Machines — إدارة علاء محمد.

## الرؤية
مرجع موثق للخامات والمواد اللاصقة والشحوم والدهانات والصبغات والمعادن والنجارة ومواد البناء، مع أسماء السوق المصري ومراحل التصنيع والحاسبات الفنية.

## نطاق الإصدار الأول
- Android: Kotlin, Jetpack Compose, Material 3, Arabic RTL.
- Offline-first: Room مع تحديثات محتوى موثقة.
- أقسام الصناعات، البحث، المفضلة، قاموس أسماء الخامات.
- صفحات صناعية تعرض المكونات والمواصفات والمعدات ومراحل التصنيع واختبارات الجودة.
- حاسبة كميات وتكاليف تعتمد فقط على تركيبات موثقة.
- تصنيف المحتوى: معلومات عامة / مرجع منشور / مختبر / إنتاج مثبت.
- تحذيرات السلامة ومصادر المراجع وتواريخ المراجعة لكل مادة.
- مشاركة بطاقات FG Machines التعليمية.

## قواعد المحتوى
لا تُقدَّم التركيبات غير المختبرة بوصفها صالحة للبيع أو الإنتاج. تراجع مخاطر المواد والتوافق والتراخيص قبل نشر تعليمات التشغيل، وتُمنع وصفات الاستخدام الخطِر غير المأمون.

## خطة العمل
1. تأسيس مشروع Android قابل للبناء واختبارات CI.
2. مخطط بيانات المنتجات والخامات والمراجع والمخاطر.
3. الواجهة الرئيسية والبحث والقاموس وصفحات المواد.
4. حاسبات التركيب والتكلفة واختبارات الدقة.
5. إضافة المحتوى الموثق وتجربة Android 15.

## الحالة
الإصدار التجريبي 0.2.0 متاح: Room، المفضلة، واجهات عربية/إنجليزية، حاسبات الكتلة والتكلفة، ومحتوى تعريفي موثق أولي. الموضوعات الـ71 ما زالت عناوين غير محققة؛ لا توجد وصفات إنتاج معتمدة.

للبناء: Gradle 8.9 + JDK 17 + Android SDK 35، ثم `./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug`. اختبارات الجهاز: `./gradlew :app:connectedDebugAndroidTest`. راجع `docs/DEVELOPMENT_STATE.md` للأدلة والمهام المتبقية.
